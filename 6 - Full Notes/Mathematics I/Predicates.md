# Predicates

#### Predicates definition:
φ(x) is something that is either true or false about a member x of some universe. We say that it holds for x or that satisfies φ when φ(x) is true.

E.g.
- φ(x)=“x is called Michael” is probably holds for some people in this room and doesn’t hold for most.
-  φ(x)=“x is an apple” is a predicate in the universe of fruit.
- φ(x)=“x is even” is a predicate about the natural numbers, 2 satisfies φ, 741does not
#### Naïve Set theory: 
Given a predicate φ we can construct a subset of a universe X that contains elements to satisfy φ.

The subset of X that contains those elements that satisfies φ is usually denoted by:

{ x | x ∈ X and φ(x)}

E.g.
- {x | x ∈ ℕ and x is even} = {0, 2, 4, …}
- {x | x ∈ ℝ} and x² + x - 6 = 0} = {2.0, -3.0}
- X and {x | x ∈ X} are the same
