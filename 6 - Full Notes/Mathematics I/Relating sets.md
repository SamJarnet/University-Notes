# Relating sets

#### Subsets:

A basic relationship between sets is the subset relationship.

A set X is a subset of Y when every element of X is also an element of Y.

#### Notation:

X ⊆ Y

Fact: Every set satisfies X ⊆ X
Fact: For any set X we have ∅ ⊆ X

It is sometimes useful to talk about sets that are strictly larger or smaller, we write X ⊂ Y to mean that X ⊆ Y and there exists y ∈ Y and y ∉ X.

To show that two sets X and Y are equal it is enough to show
- X ⊆ Y and
- Y ⊆ X

To show an ordered pair use ():
(0,1) != (1,0)

In general (x, y) = (z, w) if x=z and y=w
- This is sometimes called "the defining property of an ordered pair
