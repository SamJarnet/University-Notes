# Taxonomy of Functions

#### Injective Functions:
- A function f: X -> Y is injective (or one-to-one or into) if it satisfies:
	- for all $x, x^{'}$ in X, $f(x) = f(x^{'})$ implies that $x=x^{'}$ 
	- so different elements go to different elements

![[Pasted image 20241028220749.png|500]]

#### Surjective Functions: 
- A function f : X -> Y is surjective (or onto) if for all y ∈ Y there exists an x ∈ X such f(x)=y
- In other words, f is surjective if its range is all of Y

![[Pasted image 20241028221049.png | 500]]

#### Bijective Functions:
- A function is said to be bijective (or one-to-one correspondence) if it is both injective and surjective.

#### Isomorphism Theorem:
- Theorem: Let f : X→Y be a function. Then the following are equivalent
	- f is bijective (injective and surjective) 
	- f has an inverse
