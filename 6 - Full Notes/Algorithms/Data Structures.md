# Data Structures

#### Encapsulation:
- In the OO-methodology you seperate the interface from the implement 
- The implementation is hidden (encapsulated) and may be changed without affecting how the class is used
- This is done in classes with the set of public methods being the interface

#### Abstract Data Types:
- ADTs are similar to interfaces but programing language-independent
- An ADT specifies the operations through which a certain data structure (e.g. arrays, linked lists, trees) can be accessed
- Their purpose is to allow you to declare your intentions
- You are entering into an agreement that you only intend to use the underlying data structure in the way specified by the ADT

#### Say it with an ADT
- Common ADTs include [[Stacks]], [[Queues]], [[Lists]] [[sets (Algorithmics)]] and [[Maps]]
- There are many possible implementations for an ADT, some far from obvious
- ADTs are an abstraction away from implementation
- By declaring your intentions you are making your algorithms easier to understand and maintain
