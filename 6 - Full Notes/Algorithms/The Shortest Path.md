# The Shortest Path


#### Travelling Salesmen Problem:
- Definition:
	- Given a set of cities and tables of distances between them, find the shortest tour that goes through every city exactly once and returns to start
- Brute force:
	- Enumerating every possible route and selecting the shortest
	- Takes half a second with 10 cities
	- With 100 cities it would take $2.72\times 10^{39}$ age of universes
	- As 99! is much bigger than 9!
