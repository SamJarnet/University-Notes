# Lists

#### Lists:
- A list is a collection where the order of elements is important
- Repetition are allowed
- You can:
	- add (at a specified position) - elements shifted to the right before adding new element
	- remove (from a specified position) - subsequent elements shifted to the left
	- set (at a position)
	- get (from a specified position)
- Java has a $List<T>$ interface
- Java provides specified implementations as $ArrayList<T>$ and $LinkedList<T>$
