# Python Networking

#### What is a socket?
- Represents a way to send and receive data
- Allows IPv4 and IPv6 addressing
- UDP, TCP etc
- Broadcast/Unicast
- STREAM means r/w TCP
- "DataGRAM" means UDP
- RAW is for lower level like ICMP etc
