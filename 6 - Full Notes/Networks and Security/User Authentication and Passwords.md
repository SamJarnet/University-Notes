# User Authentication and Passwords

#### User Authentication:
- Fundamental building block and the primary line of defence
- Authentication: the determination of the identity of someone or something 
- Encompasses two functions:
	- Identification: a user identifies itself to a system by presenting a credential (ID)
	- Verification: the system verifies the user by the exchange of authentication information (PW)

- Four general means of user authentication (alone or in combination):
	- Something the individual knows (e.g. PIN)
	- Something the individual possesses (e.g. Key)
	- Something the individual is (static biometrics) (e.g. Fingerprint)
	- Something the user does (dynamic biometrics) (e.g. Signature)
