# SPI Bus

#### Specs:
- Signals: Clock, output, input, select
- Clock up to 10MHz
- Select input is used to choose one IC to use
- Useful to communicate with: radios, touchscreens, sensors, coms chips (USB/Ethernet/etc.), flash memory, etc.
