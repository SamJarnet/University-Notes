# Interconnections


#### Interconnection structure:
- Modules in computers must be connected
- Different types of connection required for different types of unit
- [[GPU]]s
- CPU
- RAM
- network
- Disks
- Peripherals

#### Memory Connection:
- Consist of N words of equal length with unique address
- Memory:
	- Receives addresses 
	- Receives control signals
		- Read
		- Write
		- Timing
	- Receives and sends data
- "memory mapped" things appear in address space

#### CPU Connection:
 - Reads instructions and data
 - Sends control signals to other units
 - Receives and acts on interrupts
