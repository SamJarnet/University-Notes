# MLE & Linear Regression

#### The core task: Fitting models to data
- The general setup: 
	- We observe some data $D$, and we assume it was generated by a probabilistic model $p(D|\theta)$ with unkown parameters $\theta$
- Examples:
	- We observe the heights of 100 people. We might assume the data comes from a Gaussian distribution, $N (µ, σ^2 )$. The parameters to estimate are $θ = (µ, σ^2 )$.
	- We flip a coin 100 times and observe 60 heads. We might assume the data comes from a Bernoulli distribution with parameter $ϕ$. The parameter to estimate is $θ = (ϕ)$.
- How do we choose the best parameters $\theta$ to explain the data we saw.
