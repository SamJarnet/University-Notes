# Context-Free Grammars I 

#### Definition
- Informally, formal grammars are a method for describing languages
- It is a way of understanding the relationships between elements in a sentence
- A context-free grammar (CFG) is a set of rules that allows to specify which sentences in a language are well formed and belong to the language
- CFGs play an important part in a compiler workflow, in parsers in particular

- ![[Pasted image 20251026170838.png]]
- Above is an example of a CFG for a fraction of English
- This way of displaying grammar is known as the Backus-Naur form
- ⟨SENTENCE⟩, ⟨NOUN-PHRASE⟩, etc. are variables
- flower, likes, etc. are all constants
- Each rule specifies how the variable on the left of $\rightarrow$ can be replaced by a string of symbols on the right.
- Some sentences can be derived from this grammar:
	- a cat sees 
	- the dog sees the cat 
	- a cat with a flower likes the dog
- We can recursively apply the rules from a starting point
- We replace variables with the corresponding strings by applying the rules
- The process ends when we obtain a string of constants so no further substitution is possible
- This process is called derivation.

#### Definition
- A CFG $G$ is a quadruple $(N, Σ, P, S)$ where:
	- $N$ is a finite set of variables (also called "non-terminal symbols")
	- $\sum$ is a finite set of constants (also called "terminals")
	- $P \subseteq N \times (N \cup \Sigma)^*$ are the rules (also called "productions")
	- $S \in N$ is the start variable
- we use  $A, B, C ...$ to denote variables; $a, b, c,...$· to denote constants; $α, β, γ, ...$to denote strings from $(N ∪ Σ)^∗$;
- We will use the shorthand $A \rightarrow \alpha$ to mean $(A, \alpha) \in P$ 
- We will use the shorthand $A → α_1 | α_2 | . . . | α_k$ for:
	- $A → α_1, A → α_2, . . . , A → α_k$ .

#### Example 1
- G = ({S}, {a, b}, {(S, aSb),(S, ϵ)}, S)
	- is a CFG for the language $\{a ^n b ^n | n ≥ 0\}$ 
- $S$ is the start variable
- $\{a. b\}$ is the set of constants
- Rules are $S \rightarrow aSb | \epsilon$ 
- The above grammar generates e.g. $aabb$
	- $S ... aSb ... aaSbb ... aabb$ 

#### Derivations (Formally)
- We define a relation $\xRightarrow{k}$ between strings, which means "derivable in $k$ steps"
- Let $G$ be a CFG. Define relations $\xRightarrow{k}$ on $(N + \Sigma)^*$ as follows:
	- $\alpha \xRightarrow{0} \alpha$;
	- if $\alpha \xRightarrow{k} \beta, \beta = \beta _1 A \beta _2$ and $a \rightarrow \gamma$ then $\alpha \xRightarrow{k+1} \beta _1 \gamma \beta _2$ 
- Write $\alpha \xRightarrow{} \beta$ if $\alpha \xRightarrow{k} \beta$ for some $k$ 
- If $α ⇒ β$ we say that $β$ is derivable from $α$;
- If $S ⇒ α$ then α is a sentential form (where S is start variable);
- If $S ⇒ x (x ∈ Σ ^∗ )$ $then x is called a sentence, (a sentence contains only constants)

#### Language generated by CFG

The language generated by a CFG $G$ is the set of all its sentences:
- Given a CFG $G = (N, \Sigma, P, S)$, 
	- $L(G) = \{x \in \Sigma ^* | S \Rightarrow x\}$ 
- A language is called context-free (CFL) if there exists a CFG $G$ such that:
	- $L = L(G)$
